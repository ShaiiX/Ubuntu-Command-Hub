<h1 align="center">Ubuntu Command Hub</h1>

<p align="center">
  <em>Guía visual e interactiva de comandos de Linux.<br>
  Pensada para consulta diaria.</em>
</p>

<br>

## Categorías

| Categoría | Comandos |
|---|---|
| Sistema y navegación | `cd`, `ls`, `pwd`, `man`, `clear`, `echo`, `date`, `alias` |
| Archivos y directorios | `cp`, `mv`, `rm`, `mkdir`, `touch`, `find`, `tar`, `zip`, `unzip`, `cat`, `less`, `head`, `tail`, `nano`, `vim` |
| Permisos y usuarios | `chmod`, `chown`, `chgrp`, `umask`, `adduser`, `usermod`, `passwd`, `sudo`, `whoami`, `id` |
| Procesos y sistema | `ps`, `top`, `htop`, `kill`, `systemctl`, `uname`, `df`, `free`, `uptime`, `service`, `nohup` |
| Red | `ip`, `ping`, `traceroute`, `ss`, `netstat`, `nslookup`, `dig`, `wget`, `curl`, `ssh`, `scp` |
| Paquetes | `apt update`, `apt upgrade`, `apt install`, `apt remove`, `apt autoremove`, `apt search`, `dpkg` |
| Disco y almacenamiento | `lsblk`, `fdisk`, `df`, `du`, `mount`, `umount`, `blkid` |
| Logs y diagnóstico | `journalctl`, `dmesg`, `tail`, `grep`, `systemd-analyze` |
